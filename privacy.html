Ads Assistant 隐私政策

本政策说明 Ads Assistant 如何访问、使用、保存和分享 Google Ads 数据。

应用介绍使用条款联系

生效日期：2026 年 11 月 1 日

访问的数据与用途

经操作者通过 Google OAuth 同意后，应用使用 Google Ads 授权范围（https://www.googleapis.com/auth/adwords）访问操作者有权访问的 Google Ads 数据。根据所执行的任务，数据可能包括客户账号标识、账号名称、广告系列、广告、关键词、预算、出价，以及展示、点击、费用、转化等报告指标。这些数据用于操作者要求的查询、投放分析和广告管理。

凭据与数据保存

OAuth 客户端凭据及刷新令牌保存在运行此工具的 Mac 本地，并使用本机文件访问权限限制访问。操作者应妥善管理该设备、备份以及可访问该设备的账号。任务执行期间读取的广告数据也可能保留在 Cindy 的对话记录、工具输出或操作者生成的报告中；相关记录与备份需要在其保存位置分别管理和删除。

AI 处理及第三方服务

本工具通过 Cindy 使用操作者配置的 AI 服务来执行任务。用于完成任务的广告数据、工具结果和对话内容可能发送给该 AI 服务进行推理与分析；具体处理地点、留存期限以及服务商的数据使用规则取决于操作者选用的服务和账号设置。操作者应在使用前确认其有权向所选服务提供这些数据。

应用还会将 API 请求发送给 Google，以获取数据或执行操作者指示的操作。本工具本身不提供广告数据出售功能。任何新增的数据用途或接收方都应先更新本说明，并在需要时取得相应授权。

权限撤回与删除

操作者可在 Google 账号的第三方连接管理页面撤回本应用的授权。撤回后，本应用不能继续使用该授权访问 Google Ads。撤回授权不会自动删除已经生成的报告、对话记录或备份；这些内容须在对应保存位置删除。需要协助时，可通过下方联系邮箱提出请求。

Google API 数据使用

本应用对从 Google API 收到的信息的使用和转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。实际接入的 AI 服务和处理流程也须符合适用的 Google 数据使用要求。

说明更新

应用功能、保存方式或所使用的第三方服务发生变化时，负责人应更新本页，并在涉及新的数据用途时告知受影响的操作者。
